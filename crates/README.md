

# Crates

- marpii: main Vulkan wrapper
- marpii-commandes: CommandBuffer related helpers.
- marpii-descriptor: Descriptor(Set) related helpers
- marpii-rmg: ResourceManagingGraph implementation. Much higher level compared to *raw* vulkan/marpii

Take a look at [Glacier](https://gitlab.com/tendsinmende/glacier/) for a real-world library using those crates to provide a comprehensive rendering framework.
